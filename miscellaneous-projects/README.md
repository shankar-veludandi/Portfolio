# Miscellaneous ML Projects

This directory contains a handful of additional machine-learning projects showcasing classification, regression, collaborative filtering, and sequence-modeling techniques. Click into each folder for full setup instructions, code, and results.

| Project | Description |
| ------- | ----------- |
| [breast-cancer-classifier](./breast-cancer-classifier) | Classify tumors in the Wisconsin Breast Cancer dataset using data preprocessing, feature selection, and ensemble models (Random Forest & XGBoost). |
| [customer-churn-predictor](./customer-churn-predictor) | Predict customer churn via exploratory data analysis, feature engineering, and classification algorithms (Logistic Regression, Decision Trees, Random Forest). |
| [movie-rating-predictor](./movie-rating-predictor) | Build and evaluate rating-prediction models on MovieLens data using collaborative filtering (matrix factorization) and regression techniques. |
| [sequence-modeling-and-embeddings](./sequence-modeling-and-embeddings) | Explore sequential data tasks with RNN/LSTM/Transformer architectures and token embedding methods (PyTorch & Hugging Face). |
