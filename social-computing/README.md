# Social Computing NLP Projects

This directory contains two end-to-end NLP-based social media projects showcasing feature engineering, model training, and evaluation procedures on real-world data.

| Project                  | Description                                                                                                               |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------- |
| [gender-prediction](gender-prediction)     | Predict Twitter user gender from recent tweets, profile descriptions, UI color preferences, and confidence scores using Multinomial Naive Bayes. |
| [reddit-engagement](reddit-engagement)     | Classify r/AskReddit posts into high or low engagement categories based on TF–IDF text features, sentiment analysis, and temporal metadata with an SVM model. |
