# Statistical & Tabular Machine Learning

A suite of projects applying statistical modeling, regression, and classification techniques to tabular data.

| Project Folder                                            | Description                                                                                                     |
|-----------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------|
| [nba-financial-performance-analysis](./nba-financial-performance-analysis) | Analyze NBA franchise financial decisions (salary, luxury tax, contracts) to predict on-court performance.        |
| [chemsus-biodegradability](./chemsus-biodegradability)                      | Predict molecular biodegradability via logistic regression, SVM, and feature-selection on molecular descriptors. |
| [customer-churn-predictor](./customer-churn-predictor)                      | Forecast customer churn using EDA, feature engineering, and classification algorithms.                           |
| [breast-cancer-classifier](./breast-cancer-classifier)                      | Classify tumors in the Wisconsin Breast Cancer dataset with Random Forest and XGBoost ensembles.                |
| [movie-rating-predictor](./movie-rating-predictor)                          | Build and evaluate rating-prediction models on MovieLens data using collaborative filtering and regression.     |
| [invasive-insect-spread-predictor](./invasive-insect-spread-predictor)      | Spatio-temporal modeling of invasive insect spread using environmental covariates and occurrence records.        |
