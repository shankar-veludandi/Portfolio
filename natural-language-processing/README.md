# Natural Language Processing

This directory contains end-to-end NLP projects showcasing text feature engineering, modeling, and evaluation on real-world data.

| Project Folder           | Description                                                                                       |
|--------------------------|---------------------------------------------------------------------------------------------------|
| [gender-prediction](./gender-prediction)     | Predict Twitter user gender from tweets, profile text, and UI color choices using Naive Bayes. |
| [reddit-engagement](./reddit-engagement)     | Classify r/AskReddit posts as high/low engagement via TF–IDF, sentiment, and temporal features. |
| [sequence-modeling-and-embeddings](./sequence-modeling-and-embeddings) | Benchmark RNN/LSTM/Transformer architectures and token embeddings on sequential data tasks.       |
